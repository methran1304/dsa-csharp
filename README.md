# DSA in C#

A collection of **data structures** and **algorithms** implemented in C# for learning and practice.  
This project covers fundamental concepts like arrays, linked lists, stacks, queues, sorting, searching, and recursion — all within a clean .NET project structure.

---

## 📂 Content
```
Data Structures
	• Array
	• ArrayList (dynamic array implementation)
	• LinkedList (singly/doubly linked)
	• Stack
	• Queue
	• Data types examples

Algorithms
	• Searching
	• Linear Search
	• Binary Search
	• Sorting
	• Bubble Sort
	• Selection Sort
	• Insertion Sort
	• QuickSort
	• Recursion
	• Factorials, Fibonacci, etc.
	• Recursive pathfinding
	• Pathfinding
	• Maze/path solver using recursion
```
